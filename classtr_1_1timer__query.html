Detailed Description

Object holding a graphics driver timer query.

Wrapping a sequence of graphics instructions with a timer query's begin() and end() allows measuring the total time needed to execute said commands on the GPU side.

Every instance of tr::timer_query is associated with a graphics context and cannot outlive its parent context.

Moved-from instances of tr::timer_query are left in a special 'invalid' state. Invalid tr::timer_query instances may not be interacted with besides moving a new value into them and checking for validity using valid().

tr::timer_query instances may be labeled and are formattable. Example format output: "My query" (OpenGL ID: 5).
