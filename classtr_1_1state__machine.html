tr::state_machine Class Reference

State machine manager class. More...

Detailed Description

The state machine works with the polymorphic tr::state. States inherited from tr::state may overload the handle_event() method used to handle incoming events, the update() method used to update the state, and the draw() method used to draw the state.

handle_event() and update() return tr::next_state, which is a sum type containing either a state, tr::keep_state, or tr::drop_state. If tr::keep_state is returned, the state machine keeps the current state, and if tr::drop_state is returned, the state machine drops the current state and becomes empty.

update() and draw() are benchmarked internally and their benchmarks are gettable.
