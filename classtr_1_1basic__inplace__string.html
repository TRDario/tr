Detailed Description

template<typename CharT, usize Capacity, typename Traits = std::char_traits<CharT>>
class tr::basic_inplace_string< CharT, Capacity, Traits >

tr::inplace_string mirrors the interface of a standard string, but its characters are stored inplace within the object. Additionally, unlike a standard string, it is not guaranteed to be NUL-terminated.
