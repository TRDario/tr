tr::static_string< Capacity > Class Template Reference

Inplace-allocated fixed-capacity string. More...

Detailed Description

template<usize Capacity>
class tr::static_string< Capacity >

tr::static_string mirrors the interface of a standard string, but its characters are stored inplace within the object. Additionally, unlike a standard string, it is not guaranteed to be NUL-terminated.
