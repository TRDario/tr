Detailed Description

Static, immutable index buffer.

tr::static_index_buffer represents a graphics buffer used to store index data. Unlike tr::dynamic_index_buffer, it represents a single, static allocation of immutable data, making it suitable for scenarios where the index data is constant.

Strictly speaking, instances of tr::static_index_buffer are only containers for these underlying buffer objects. This means, for example, that setting a static index buffer on a graphics context does not set the literal tr::static_index_buffer object at a specific location in memory, but rather the value it contains. If the value is moved to a different instance of tr::static_index_buffer, that value will still be set on the context. If the instance is overriden with a new value, the old value is destroyed and the graphics context will no longer have a set index buffer.

Every instance of tr::static_index_buffer is associated with a graphics context and cannot outlive its parent context.

Moved-from instances of tr::static_index_buffer are left in a special 'invalid' state. Invalid tr::static_index_buffer instances may not be interacted with besides moving a new value into them and checking for validity using valid().

tr::static_index_buffer instances may be labeled and are formattable. Example format output: "My index buffer" (ID: 3, IBO: 5).
