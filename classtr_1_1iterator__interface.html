Detailed Description

template<typename Iterator, typename DeducedBrackets = void>
class tr::iterator_interface< Iterator, DeducedBrackets >

Interface an iterator class can inherit from to automatically derive various functions from a small subset of basic operators (operator++, operator--, operator+=, operator*).

operator++(int) is synthesized when operator++ is defined.
operator--(int) is synthesized when operator-- is defined.
operator+, operator-, and operator-= are synthesized when operator+= is defined.
operator-> is synthesized when operator* is defined and returns a reference type.
operator[] is synthesized when operator+ and operator* are defined and/or synthesized.

Template Parameters
IteratorIterator type to implement the interface for.
DeducedBracketsOptional type used in automatic deduction of bracketed values in operator[].
