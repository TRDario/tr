Detailed Description

template<typename Object>
class tr::mapped_graphics_buffer_object< Object >

Map of a graphics buffer object.

tr::mapped_graphics_buffer_object represents the CPU mapping of a graphics buffer object and models access to it as such. The object is automatically unmapped when the map is destroyed.

Every instance of tr::mapped_graphics_buffer_object is associated with a graphics context, as well as with a buffer, and cannot outlive either.

Moved-from instances of tr::mapped_graphics_buffer_object are left in a special 'invalid' state. Invalid tr::mapped_graphics_buffer_object instances may not be interacted with besides moving a new value into them.
